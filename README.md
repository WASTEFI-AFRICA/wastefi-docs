# WasteFi Documentation

> Financial Inclusion Through Waste Collection - Powered by Open Material Standards

This repository contains the complete documentation for the WasteFi platform, including user guides, API references, technical specifications, and developer resources.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📚 Documentation Structure

- **Guide** - User guides, tutorials, and getting started
- **API** - API reference and integration guides
- **About** - Vision, mission, and project information
- **Technical** - Architecture, specifications, and standards

## 🏗️ Built With

- [VitePress](https://vitepress.dev/) - Modern static site generator
- [Vue 3](https://vuejs.org/) - Progressive JavaScript framework
- Markdown - Simple content authoring
