# Contributing to WasteFi Documentation

Thank you for your interest in contributing to WasteFi! This document provides guidelines for contributing to the documentation.

## How to Contribute

### Reporting Issues

- Use the GitHub issue tracker
- Check if the issue already exists
- Provide clear descriptions and examples
- Include screenshots for UI-related issues

### Suggesting Enhancements

- Open an issue with the "enhancement" label
- Describe the enhancement and its benefits
- Provide examples or mockups if applicable

### Contributing Documentation

1. **Fork the Repository**
   ```bash
   git clone https://github.com/wastefi/wastefi-docs.git
   ```

2. **Create a Branch**
   ```bash
   git checkout -b docs/your-feature-name
   ```

3. **Make Your Changes**
   - Follow the existing documentation style
   - Use clear, concise language
   - Include code examples where appropriate
   - Test your changes locally

4. **Commit Your Changes**
   ```bash
   git commit -m "docs: description of your changes"
   ```

5. **Push and Create PR**
   ```bash
   git push origin docs/your-feature-name
   ```

## Documentation Style Guide

### Writing Style

- Use clear, simple language
- Write in present tense
- Use active voice
- Be concise but complete
- Include practical examples

### Markdown Conventions

- Use ATX-style headers (`#` for h1, `##` for h2, etc.)
- Use fenced code blocks with language identifiers
- Use relative links for internal pages
- Include alt text for images

### Code Examples

- Include complete, working examples
- Add comments for clarity
- Follow the project's coding standards
- Test all code examples

## Review Process

1. All contributions are reviewed by maintainers
2. Feedback will be provided via PR comments
3. Changes may be requested before merging
4. Approved PRs are merged by maintainers

## Community Guidelines

- Be respectful and inclusive
- Help others learn and grow
- Provide constructive feedback
- Follow our Code of Conduct

## Questions?

- Join our [Discord community](https://discord.gg/wastefi)
- Email: contribute@wastefi.org
- Open a discussion on GitHub

Thank you for contributing to WasteFi! 🙏
